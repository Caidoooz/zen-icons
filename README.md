# Zen Icons 

Zen Icons is an open-source, ultra-lightweight SVG icon library crafted with precision for modern user interfaces, dashboards, and mobile applications.

## ✨ Features
- **Scalable & Pixel-Perfect:** 24x24 grid baseline.
- **Developer-Friendly:** Easily imported into React, Vue, Tailwind, or vanilla HTML/CSS.
- **Open-Source:** 100% free under the MIT License.

## 📁 Repository Structure
- `/icons`: Raw SVG files ready for direct use.
- `/react` (Planned): Automated component wrapper.

## 🚀 Roadmap & AI Integration
We are actively building an automated CLI workflow using OpenAI Codex to:
1. Automatically optimize SVG code paths and strip metadata.
2. Generate typed React/Vue component code directly from raw SVGs on pull requests.
3. Validate visual accessibility and line weight consistency across the library.
